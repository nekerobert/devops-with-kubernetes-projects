# DevOps with Kubernetes — Projects

My practical exercises and projects for the University of Helsinki DevOps with Kubernetes 2026 course.

## Course information

- **Course:** DevOps with Kubernetes
- **Institution:** University of Helsinki
- **Language:** Node.js
- **Containerization:** Docker
- **Orchestration:** Kubernetes
- **Container Registry:** Docker Hub

## Repository structure

Applications and their associated Kubernetes configurations are organized into individual directories.

Each exercise is versioned through a GitHub release matching its exercise number. The links above point to the corresponding application directory at that exercise's tag.
